# شبكة الطرق بمحافظة البريمي — الإصدار ٢٫٣ (تصحيح محرك الخرائط)

تطبيق معرض أكتوبر العمران ٢٠٢٦، دائرة الطرق بمحافظة البريمي.

## لماذا ظهرت رسالة jsDelivr؟

الإصدار ٢٫٢ كان يطلب `maplibre-gl@6.14.0/dist/maplibre-gl.js` عبر عنصر `<script>` قديم. بدءًا من الإصدار السادس ينبغي تحميل نسخة **ES module** المسماة `maplibre-gl.mjs`، مع ملفات العامل (worker) التابعة لها. المسار السابق غير صحيح، حتى عندما يكون اتصال الإنترنت جيدًا.

## حل سريع بمجرد رفع النسخة

- يحمّل `assets/bootstrap.js` المكتبة من ملفات الموقع المحلية **إن وجدت**.
- عند غياب الملفات المحلية، يجرب النسخة الصحيحة من UNPKG ثم jsDelivr. لذا قد تعمل النسخة بعد رفعها مباشرة إذا سمحت الشبكة بذلك.
- **للاستغناء عن CDN عند زيارة الموقع، فعّل GitHub Actions كما في الخطوات التالية.** الحزمة ZIP لا تحتوي على المكتبة الثنائية سلفًا؛ يقوم GitHub بتنزيلها **مرة أثناء عملية النشر** وإضافتها إلى الموقع المنشور.

## الإعداد الموصى به في GitHub Pages (الاستضافة المحلية التلقائية)

1. فك الضغط وارفع **جميع محتويات** مجلد `AlBuraimi-Roads-Touch` إلى جذر المستودع، مع مجلدَي `assets` و`.github` ومجلد `scripts`. تأكد من وجود الملف `.github/workflows/deploy-pages.yml` في المستودع.
2. افتح **Settings → Pages → Build and deployment → Source** واختر **GitHub Actions** بدل `Deploy from a branch`.
3. افتح **Actions** وتأكد من نجاح سير العمل المسمى **نشر خريطة البريمي مع مكتبة محلية**. يمكنك تشغيله يدويًا من **Run workflow** إذا لزم.
4. افتح رابط GitHub Pages ثم حدّث الصفحة. على الهاتف، افتح نافذة خاصة أو احذف بيانات الموقع إذا بقيت نسخة قديمة مخزنة.

**بعد نجاح GitHub Actions:** سيخدم GitHub Pages محرك MapLibre (ES modules وWorker وCSS) من `assets/vendor/` على **نفس نطاق الموقع**، كما ينشر ملف حدود محافظة البريمي بشكل محلي تحت `assets/buraimi-boundary.geojson`. لا يحتاج جهاز المعرض إلى زيارة jsDelivr أو UNPKG أو GitHub Raw. يظل **OpenFreeMap** مطلوبًا لتحميل بيانات الطرق وAWS/Mapzen عند تفعيل التضاريس.

**إذا كان مستودعك يستخدم فرعًا غير `main`:** عدّل اسم الفرع في السطر `branches: [main]` داخل `.github/workflows/deploy-pages.yml`.

## متطلبات شبكة المعرض

- يظل مصدر بيانات الخرائط الحية: `https://tiles.openfreemap.org`.
- طبقة الارتفاعات عند تشغيلها: `https://s3.amazonaws.com`.
- بيانات الطرق من OpenStreetMap عبر OpenFreeMap، وليست قائمة معتمدة للطرق التابعة للوزارة.
- بيانات الحدود مأخوذة من GADM 3.6 عبر [oman-data-bank](https://github.com/NasserAlbusaidi/oman-data-bank)، وهي مرجعية لأغراض العرض ولا تقوم مقام ملف GIS رسمي.

إذا ظهرت مشكلة مع حدود المحافظة أو تحميل الطرق بعد عمل MapLibre، افحص إعدادات الاتصال بخوادم الخرائط. إصلاح المكتبة لا يعني أن بيانات OpenStreetMap أصبحت تعمل بلا إنترنت.

## تنبيهات

- موقع `?admin=1` ليس نظام دخول آمنًا، وإنما واجهة إدارة محلية.
- قد تظهر أسماء مواقع بالإنجليزية إذا لم توجد تسمية عربية في قاعدة OpenStreetMap.
- حافظ على النسخة القديمة في نسخة احتياطية قبل استبدال الملفات في GitHub.

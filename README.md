# شبكة الطرق بمحافظة البريمي — إصدار ٢٫٤ (دون Actions)

واجهة معرض أكتوبر العمران ٢٠٢٦ — دائرة الطرق بمحافظة البريمي.

## نشر بسيط على GitHub Pages

1. ارفع **محتويات هذا المجلد** (بما فيها `index.html` ومجلد `assets`) إلى جذر مستودع GitHub.
2. انتقل إلى **Settings → Pages → Build and deployment**.
3. اختر **Source: Deploy from a branch** وليس GitHub Actions.
4. حدد **Branch: main** و **Folder: / (root)** ثم اضغط Save.
5. افتح رابط الموقع بعد اكتمال النشر. لا تحتاج إلى `npm` أو workflow أو سير عمل للنشر.

## كيف يحمل MapLibre؟

يحاول التطبيق أولًا العثور على `assets/vendor/maplibre-gl.mjs` محليًا، وإذا لم يجده يجرب بالتتابع UNPKG وjsDelivr وesm.sh. **ملفات المكتبة غير مضمّنة في هذه الحزمة حاليًا**؛ لذلك يعتمد التشغيل لأول مرة على السماح بالاتصال بأحد تلك المصادر ما لم تضف المكتبة يدويًا.

### تشغيل دون الاعتماد على CDN (مناسب لشبكات الجهات الحكومية)

1. من جهاز تتوفر عليه شبكة إنترنت تسمح بالتنزيل افتح: https://cdn.jsdelivr.net/npm/maplibre-gl@6.13.0/dist/
2. نزّل الملفات الأربعة الآتية بالضبط من الإصدار **6.13.0**: `maplibre-gl.mjs` و`maplibre-gl-shared.mjs` و`maplibre-gl-worker.mjs` و`maplibre-gl.css`.
3. ضعها في `assets/vendor/` ثم ارفعها إلى مستودع GitHub مع بقية الملفات.
4. أضف أيضًا ملف ترخيص المكتبة `LICENSE.txt` من https://cdn.jsdelivr.net/npm/maplibre-gl@6.13.0/LICENSE.txt إلى `assets/vendor/`.
5. تأكد أن الروابط `https://YOUR_USER.github.io/YOUR_REPO/assets/vendor/maplibre-gl.mjs` و`.../maplibre-gl-worker.mjs` تعرض الملفات (بدل 404).

لا تحتاج إلى GitHub Actions حتى في حالة استضافة ملفات المكتبة محليًا. وتظل **اتصالات بيانات الخرائط** بـ `tiles.openfreemap.org` ضرورية عند عرض طرق OpenStreetMap، وكذلك بيانات الارتفاع عند تشغيل التضاريس.

## حدود المحافظة

التطبيق يبحث أولًا عن الملف المحلي `assets/buraimi-boundary.geojson`. **هذا الملف غير مضمَّن** في الحزمة الحالية؛ عند عدم وجوده يحاول قراءة ملف `oman-governorates.json` العام من GitHub Raw، ثم مصدر بديل، ويستخرج منه محافظة البريمي. إن كانت الشبكة تمنع تحميل الحدود، ستظل الخريطة مخفية بدل عرض الإمارات أو مناطق غير موثوقة.

لمنع هذا الاعتماد الخارجي: نزّل مجموعة المحافظات من https://raw.githubusercontent.com/NasserAlbusaidi/oman-data-bank/main/public/oman-governorates.json ثم استخرج ميزة محافظة البريمي بصيغة GeoJSON واحدة واحفظها باسم `assets/buraimi-boundary.geojson`. لا تستخدم حدودًا تخمينية بوصفها حدودًا معتمدة.

## تنبيهات

- أسماء الطرق وتصنيفاتها مستمدة من OpenStreetMap، ولا تعني أن كل الطرق تتبع وزارة النقل والاتصالات وتقنية المعلومات.
- لوحة الإدارة `?admin=1` واجهة محلية وليست تسجيل دخول محميًا.
- قد تظل بعض الأسماء الإنجليزية لعدم توفر اسم عربي في المصدر.
- النسخة لا تحمل بيانات جميع طرق المحافظة محليًا، ولا يمكن عرض خريطة الطرق دون اتصال خارجي من دون تجهيز بيانات خرائط مستقلة.
- إذا ظل التطبيق يعرض نسخة قديمة، امسح بيانات موقع GitHub Pages من المتصفح أو افتحه في نافذة خاصة، ثم أعد المحاولة.

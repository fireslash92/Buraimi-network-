# شبكة الطرق الأسفلتية بمحافظة البريمي — v5.0

**من تصميم دائرة الطرق بمحافظة البريمي — معرض أكتوبر العمران ٢٠٢٦**

تطوير مباشر للإصدار 4.0. إضافة دليل مرجعي للطرق المستخرجة من صورة المخطط الهندسي التي أرفقها المستخدم، مع الاحتفاظ بتصفح مكونات KMZ (27 موقعًا) وخريطة OpenStreetMap والعرض الكامل/ثلاثي الأبعاد وميزات النفاذ.

## ملفات المشروع

- `index.html` الواجهة الرئيسية
- `assets/road-catalog.json` **جديد**: 22 طريقًا (3 وطني، 2 شرياني، 3 ثانوي، 11 موزع، 3 محلي)
- `assets/road-components.geojson` بيانات المنشآت 27 نقطة من KMZ، كما هي
- `assets/app.js` وظائف دليل الطرق، البحث والتصنيف والربط المشروط مع منشآت KMZ
- `assets/styles.css` تصميم دليل الطرق وشاشات اللمس
- `sw.js` تحديث الإصدار المخبأ

**ضروري: لا تحذف `assets/buraimi-boundary.geojson` الموجودة في GitHub!** لم تُضمّن ضمن الحزمة حتى لا نستبدل الحدود المفصلة التي اعتمدتها.

## طريقة النشر

ارفع الملفات الجديدة إلى الجذر مع إبقاء المجلد `assets` إلى جانب `index.html`. الإعداد GitHub Pages: **Deploy from a branch → main → /(root)**؛ لا يوجد GitHub Actions.

## ما الذي يعرفه التطبيق حقًا؟

- الجدول الهندسي المصور يتضمن أسماء/أرقام/تصنيفات لـ22 طريقًا. الألوان مستوحاة من مفتاح المخطط: وطني أخضر، شرياني أزرق، ثانوي برتقالي، موزع بني، محلي سماوي.
- الصورة **لا تحتوي على خطوط طرق قابلة للتحليل الجغرافي الدقيق**؛ لذلك لم نرسم مسارات افتراضية فوق OpenStreetMap. النقر على الطرق الحية يعتمد على بيانات OSM، مع عرض تطابق رمز الطريق عند توفره **بوصفه تطابقًا مرجعيًا غير مؤكد جغرافيًا**.
- أرقام الطرق المتوافقة مع KMZ تتيح عرض منشآتها على الخريطة عند توفر نقاط مطابقة. طرق بلا مواقع في KMZ تبقى في الدليل دون إحداثيات مخترعة.
- **تعارض D604:** في الصورة D604 «طريق كتنة - الدقيق - الطالعي»، بينما KMZ يستخدم D604 «طريق السعف - الشويهه» (وهو قريب من مسمى D602 في الصورة). منعنا الربط الآلي لمكونات D604 إلى أن يراجعه المهندسون.
- **اختلاف N2:** المخطط يسميه «طريق السلطان ثويني بن سعيد» وKMZ يستخدم وصفًا ممتدًا للمسار. لم نفعّل الربط الآلي حتى التحقق.
- يجب ألا يُنشر ملف الصورة الأصلية ضمن مستودع عام: يوجد بأسفلها قيد استخدام داخل الوزارة. بيانات الدليل النصية المستخرجة تحتاج إلى موافقة الجهة على استخدامها أمام زوار المعرض عند الاقتضاء.
- للمسارات الملونة الدقيقة داخل الحدود، اطلب من المهندسين `SHP` أو `KML/KMZ` بخطوط `LineString` أو `GeoJSON` للمحاور، وحقول `road_code` و`road_name` و`classification`.

## تنبيه تقني

تعمل واجهة الدليل بدون اتصال أثناء التصفح إذا كانت الملفات المحلية متاحة؛ الخريطة المتجهة والتضاريس ومكتبة MapLibre تحتاج إلى المصادر الشبكية المحددة في `assets/bootstrap.js` ما لم تتم استضافتها مسبقًا محليًا. أعد تحميل GitHub Pages مع تجاوز التخزين المؤقت بعد التحديث.

# شبكة الطرق بمحافظة البريمي · الإصدار ٢٫٢

نسخة تفاعلية لمعرض أكتوبر العمران ٢٠٢٦، من تصميم دائرة الطرق بمحافظة البريمي.

## تصحيحان رئيسيان

- **حدود المحافظة حصريًا:** تُحمّل حدود محافظة البريمي من بيانات منشورة (GADM 3.6 عبر oman-data-bank) ويُرسم قناع جغرافي كامل فوق كل المساحات خارج المحافظة. الخريطة لن تظهر حتى تصبح الحدود جاهزة؛ لذلك لن تُعرض الإمارات أو المحافظات المجاورة على أنها جزء من المشروع. التصفح والتقاط الطرق وإضافة نقاط جديدة محصور داخل المضلع، وليست الحدود الإدارية محسوبة بمستطيل بسيط.
- **العربية:** MapLibre GL JS 6.14.0 يدعم تشكيل حروف العربية واتجاهها أصلاً؛ طبقات أسماء الأماكن والطرق تعطي أولوية للخاصية `name:ar` أو `name_ar` مع الرجوع للاسم الأصلي إذا غابت العربية من OSM. الخط المستخدم `Noto Sans Regular` المعتمد في OpenFreeMap. قد تظهر أسماء غير عربية عند غياب الترجمة في بيانات OpenStreetMap؛ ذلك ليس خلل تشكيل أحرف.

## طريقة التركيب

1. ارفع **محتويات** المجلد `AlBuraimi-Roads-Touch-v2.2` بجميع مجلداته إلى مستودع GitHub الحالي (أو ارفع المجلد الداخلي بعد فك الضغط). يجب أن يكون `index.html` في جذر GitHub Pages و`assets/app.js` بجواره.
2. استبدل الملفات القديمة بالكامل، بما في ذلك `sw.js`، ثم حدّث الصفحة تحديثًا قويًا أو افتح نافذة خاصة لإزالة نسخة التخزين السابقة.
3. يلزم اتصال بالإنترنت **لأول تحميل** لحدود المحافظة ومربعات OpenStreetMap عبر OpenFreeMap ومحرك MapLibre. تُخزّن الحدود محليًا على الجهاز بعد أول تحميل ناجح لسرعة العودة إليها؛ وتخزن ملفات التطبيق مؤقتًا، أما الخرائط نفسها فتبقى بحاجة للشبكة.

## مصادر البيانات ومتطلبات الاتصال

- طرق وخريطة: © مساهمو OpenStreetMap عبر OpenFreeMap (`tiles.openfreemap.org`).
- مضلع حدود المحافظة: مشروع [oman-data-bank](https://github.com/NasserAlbusaidi/oman-data-bank) المنقول عن GADM 3.6، يُحمّل من `raw.githubusercontent.com` ويُخزّن بعد النجاح. هذه **حدود مرجعية وليست حجة قانونية أو بديلًا عن حدود GIS الرسمية**.
- التضاريس الاختيارية AWS/Mapzen؛ عرض 3D يعمل على قدر قدرات الجهاز والاتصال.
- محرك الخريطة MapLibre GL JS 6.14.0 عبر CDN (`cdn.jsdelivr.net`).

إذا كانت شبكة الجهة تحظر GitHub Raw أو OpenFreeMap، فلن تستطيع الخريطة الظهور قبل السماح بالمصادر. لم نضع مستطيلًا بديلًا لأنه سيُظهر أراضي غير تابعة للمحافظة.

## ملاحظات دقيقة

- لا يمكن الجزم بالتبعية الإدارية لأي طريق اعتمادًا على OpenStreetMap وحدها؛ نحتاج سجل GIS المعتمد من الوزارة لتمييز الطرق التابعة لها فقط.
- عند غياب تسمية عربية في OpenStreetMap، يظل الاسم المتاح كما هو ولا يجري اختلاق ترجمة.
- الموقع `?admin=1` هو مجرد واجهة إدارة محلية ولا يحقق حماية بكلمة مرور أو مصادقة.

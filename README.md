# شبكة الطرق الأسفلتية بمحافظة البريمي — الإصدار 5.1 (ألوان التصنيفات)

تطوير مباشر للإصدار 5.0 من التطبيق التفاعلي المخصص لمعرض أكتوبر العمران ٢٠٢٦.
من تصميم **دائرة الطرق بمحافظة البريمي**.

## ما تغير؟

- **N — وطني:** أخضر فاتح `#7AEA7A`
- **A — شرياني:** أزرق غامق `#233EA5`
- **S — ثانوي:** برتقالي `#F8A123`
- **D — موزع:** بني غامق `#69402B`
- **L — محلي:** أزرق سماوي `#1AB3DC`

أضيف مفتاح ألوان عائم قابل للطي والاختيار. عند الضغط على تصنيف يُصفّى دليل الطرق وخطوط هذا التصنيف، وعند الضغط على «الكل» تعود التصنيفات الخمسة. تتحكم علامة «تمييز شبكة الطرق» في إظهار خطوط الطرق.

### المهم بشأن دقة المسارات

ملف KMZ الذي أُرسل سابقًا يحتوي على **نقاط منشآت** وليس خطوط المحاور. وصورة المخطط الهندسي تحتوي أسماء وتصنيفات لكن لا توفر إحداثيات هندسية للمسارات. لذلك:

1. تحتفظ الخريطة الأساسية بخطوط OpenStreetMap بلون محايد.
2. **فقط المقاطع المتاحة في طبقة `transportation_name` والتي تتطابق فيها رموز `ref` أو `route_1_ref … route_6_ref` مع أحد رموز الطرق الـ22 تُرسم بلون تصنيفها.** هذا لا يضمن اكتمال الطريق؛ وقد لا تتوفر رموز محلية كثيرة في OSM.
3. لا تلوّن الطرق اعتمادًا على فئة OSM (`primary`, `secondary`...) لأنها ليست مطابقة للتصنيف الهندسي في مخطط الدائرة.
4. يمكن لاحقًا تزويد التطبيق بملف اختياري `assets/road-routes.geojson` يحتوي على خطوط الطرق المعتمدة `LineString` أو `MultiLineString`؛ يجب أن يحتوي كل مسار على خاصية `road_code` بأحد الرموز الواردة في دليل الطرق. عندها يعرض خطوط الملف بألوانها دون توليد مسارات تخمينية. **الملف غير متضمن لأن المصدر الهندسي لم يوفر إحداثيات خطوط.**
5. إذا أُضيف ملف مسارات، يتحقق التطبيق من صحة البيانات الأساسية، لكن يلزم اعتمادها من الدائرة قبل النشر الرسمي.

## ما يجب رفعه إلى GitHub

ارفع جميع محتويات مجلد `AlBuraimi-Roads` في الحزمة إلى جذر المستودع، مع الحفاظ على `assets/buraimi-boundary.geojson` الموجودة لديك بالفعل؛ **لم نضمّن حدودًا أخرى لكي لا نستبدل ملفك المعتمد**.

أهم الملفات المعدلة:
- `index.html` — مفتاح التصنيفات العائم والإصدار الجديد.
- `assets/app.js` — مطابقة الأرقام وتلوين المسارات المتاحة وتفاعل المفتاح.
- `assets/styles.css` — مظهر المفتاح المتجاوب مع الشاشات.
- `assets/road-catalog.json` — توحيد ألوان التصنيفات.
- `assets/bootstrap.js` — تحميل الإصدار 5.1.
- `sw.js` — تحديث مفتاح التخزين المؤقت.

الاستضافة: **GitHub Pages → Deploy from a branch → main → /(root)**. لا تحتاج إلى GitHub Actions.

## حدود الاختبار

نجحت اختبارات التفاعل بمحاكاة محرك MapLibre على قياسات 390×844 و768×1024 و1440×900 و3840×2160، بما فيها تبديل التصنيف، عمل مفتاح الألوان، وظهور 22 طريقًا في الدليل. لم تُختبر تنزيلات مربعات OpenStreetMap الحية في هذه البيئة. أكّد التحميل في GitHub Pages قبل عرض المشروع على شاشات المعرض.

# خريطة شبكة الطرق بمحافظة البريمي — تجربة المعرض الغامرة v3.0

تطوير تجربة شاشة كاملة لمعرض **أكتوبر العمران ٢٠٢٦** باسم دائرة الطرق بمحافظة البريمي، امتدادًا لإصدار v2.4، دون GitHub Actions أو أدوات بناء.

## النشر دون GitHub Actions

1. احتفظ بنسخة احتياطية من المستودع الحالي، **وخاصة ملف الحدود التفصيلي** `assets/buraimi-boundary.geojson` الذي استخرجته من OpenStreetMap.
2. فك ZIP وارفع جميع الملفات والمجلدات الموجودة داخله **إلى جذر المستودع نفسه**، واستبدل `index.html` و`assets/app.js` و`assets/styles.css` و`assets/bootstrap.js` و`sw.js` وباقي ملفات المشروع المطابقة.
3. **لا تحذف ولا تستبدل الملف الموجود** `assets/buraimi-boundary.geojson`: هذه الحزمة تتعمد عدم تضمين ملف حدود قديم كي لا تطمس الحدود الدقيقة التي جهزتها أنت. ينبغي أن يظل ملف الحدود بجانب `assets/app.js`.
4. من GitHub افتح **Settings → Pages → Deploy from a branch → main → /(root)**. لا تحتاج إلى Actions.
5. بعد انتهاء النشر، افتح الرابط في نافذة خاصة أولًا للتأكد من تحديث نسخة المتصفح. استخدم `?admin=1` فقط لإظهار أدوات التحرير المحلية (وليست صلاحيات رسمية).

## التجربة الجديدة

- **الخريطة تملأ مساحة المتصفح من الحافة إلى الحافة**؛ شريط الهوية الحكومية وأدوات التحكم يظهران كعناصر شفافة فوق الخريطة.
- القوائم والتفاصيل والفلاتر **مغلقة افتراضيًا**، وتفتح عند الطلب دون الانتقال إلى صفحة أخرى.
- التدوير **360 درجة حول المحور الرأسي** عبر التواء إصبعين أو أزرار ↶ ↷؛ الإمالة **0–75 درجة** باستخدام إيماءة الإصبعين أو الأسهم والمنزلق. تدوير الخريطة 360 درجة لا يعني قلبها رأسًا على عقب، إذ يقيد MapLibre زاوية الميل.
- الأزرار: (+/−) تقريب، (⤢) إظهار المحافظة، (⌖) إعادة الشمال، (3D) إمالة وبناء المباني، (دوران تلقائي) عرض استعراضي، (جولة مرئية) زيارة مراكز المواقع.
- **العرض الاستعراضي:** يبدأ من زر «دوران تلقائي» أو تلقائيًا بعد 80 ثانية من عدم التفاعل إذا كانت خاصية تقليل الحركة معطلة. ينتهي بمجرد لمس الخريطة أو استخدام أدواتها. يمكن للمستخدم إيقافه مباشرة.
- **تفضيلات النفاذ الرقمي:** التباين المرتفع، وأحجام أكبر، وتقليل الحركة، عبر زر «؟». تحفظ محليًا على الجهاز. إن طلب نظام التشغيل تقليل الحركة، يفعل الخيار تلقائيًا.
- مفاتيح الوصول: `Q/E` للدوران، `W/S` للإمالة، `+/-` للتقريب بفضل اختصارات MapLibre، `0` لإعادة الزاوية والاتجاه، `H` للمساعدة، `F` لملء الشاشة، `T` للجولة، `Esc` لإغلاق اللوحات.
- **الإصدار أخف عند البدء:** خريطة 2D أولًا؛ عند التبديل إلى 3D يُعرض منظور مائل ومبانٍ إن توفرت؛ بيانات ارتفاع التضاريس تُحمّل عند تفعيلها من لوحة التفاصيل (تجنب البدء بتضاريس ثقيلة).

## بيانات الحدود والمحافظة

`assets/buraimi-boundary.geojson` ملف محلي مطلوب لضمان ظهور حدود البريمي قبل إظهار الخريطة. إن غاب أو تعذر تحميله، يحاول التطبيق المصدر المرجعي الخارجي للإصدار السابق، وإلا يمتنع عن إظهار الخريطة العامة كي لا يعرض مناطق خارج محافظة البريمي.

**هذه الحزمة لا تحتوي نسخة جديدة من الحدود**، حفاظًا على الملف التفصيلي الذي لديك. لا تستخدم الملف المبسط الأقدم بدلًا من ملف OpenStreetMap المحقق. هذه البيانات مرجعية ولا تعني الحدود الحكومية المعتمدة، والطرق المستقاة من OpenStreetMap ليست بالضرورة من أصول الوزارة.

## بيئة التشغيل والاتصال

- MapLibre يُحمّل كما في v2.4 من `assets/vendor` إن وفّرت ملفات المكتبة محليًا، أو عبر CDN احتياطي. هذه الحزمة **لا تتضمن ملفات مكتبة MapLibre نفسها**، لذا أبق مجلد `assets/vendor` المحلي إن كنت قد جهزته في مستودعك.
- يلزم اتصال بخدمات `tiles.openfreemap.org` لعرض الخرائط والطرق؛ وبيانات التضاريس تحتاج إلى مصدر ارتفاع خارجي عند تفعيلها.
- يوصى بأحدث Chrome أو Edge أو Safari على شاشة العرض، مع تسريع رسومي WebGL. وضع ملء الشاشة على المتصفح يحتاج ضغطة من المستخدم، ولا يمكن فرضه آليًا لأسباب أمنية.
- الأداء، والخطوط العربية لطبقات OSM، وتحميل تضاريس المنطقة بحاجة إلى اختبار على موقعك الفعلي، فلم تتوفر اتصالات خرائط خارجية ضمن اختبار الملفات هنا.
- للوصول من الهاتف إلى الوضع الأفقي والرأسي، الواجهة متجاوبة؛ عند استخدام شاشة لمس عملاقة يفضل دقة 1080p أو أعلى.

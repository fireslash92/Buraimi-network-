# شبكة الطرق بمحافظة البريمي — أكتوبر العمران ٢٠٢٦

تطبيق عرض تفاعلي باللغة العربية، من تصميم دائرة الطرق بمحافظة البريمي، لعرض مخطط الشبكة على شاشات اللمس الأفقية والرأسية خلال المعرض.

## ١. التشغيل السريع

- افتح `index.html` بمتصفح حديث. لا يحتاج التطبيق إلى تسجيل دخول أو خادم أو اشتراك لتصفح الخريطة.
- شغّل وضع ملء الشاشة من الرمز أعلى الصفحة. على شاشة لمس يمكنك التحريك بإصبع، والتكبير/التصغير بإصبعين.
- يمكن تثبيت موقع GitHub Pages على الشاشة الرئيسية ليعمل كتطبيق مثبت في المتصفح. بعد أول زيارة ناجحة إلى الموقع يمكن لمتصفح داعم لـ Service Workers استخدام الملفات المحفوظة أثناء انقطاع الاتصال، بعد اكتمال التخزين المسبق. قد تختلف قيود المتصفح.

## ٢. الرفع على GitHub Pages

1. أنشئ مستودعًا **عامًا أو خاصًا وفق سياسات مؤسستك** على GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع (وليس ملف ZIP نفسه): `index.html`, `assets/`, `manifest.webmanifest`, `sw.js`.
3. افتح إعدادات المستودع: `Settings → Pages`.
4. اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)` واضغط Save.
5. افتح رابط Pages الذي يقدمه GitHub وجرّب تكبير الخريطة وملء الشاشة على الجهاز المخصص للعرض.

> تنبيه: قد تمنع شبكة المؤسسة أو سياسات FortiGuard الوصول إلى بعض المواقع أو الاستضافات الخارجية. يُرجى مراجعة الجهة المختصة بدل محاولة تجاوز سياسات الشبكة.

## ٣. تخصيص المواقع

- عرض الزوار الافتراضي لا يُظهر أزرار التحرير.
- افتح رابط التطبيق مع اللاحقة `?admin=1` (مثل `https://USER.github.io/REPO/?admin=1`) لإظهار أدوات الصيانة: **إدارة المواقع**، تصدير البيانات، استيراد البيانات.
- اضغط **إدارة المواقع** ثم المس أي موضع على الخريطة لإضافة علامة؛ أو اختر علامة لتعديل بياناتها أو حذفها.
- تُحفظ التعديلات في مساحة التخزين المحلية للمتصفح، **ولا تنتشر تلقائيًا إلى المستودع أو إلى الأجهزة الأخرى**. استخدم زر تصدير ملف `buraimi-roads-locations.json` للاستنساخ الاحتياطي، ثم استورده في أجهزة العرض الأخرى.
- `?admin=1` وسيلة لإخفاء أدوات الصيانة من شاشة العرض المعتادة **وليست حماية أو تسجيل دخول**. لا تضع في بيانات المواقع معلومات سرية أو غير مخصصة للنشر.
- لتغيير النقاط الافتراضية المنشورة لجميع الزوار، عدّل مصفوفة `DEFAULT_POINTS` داخل `assets/app.js` ثم ارفع الملف المعدّل إلى GitHub. بعد النشر قد يلزم تحديث الكاش / إعادة تحميل التطبيق.

## ٤. استبدال الخريطة منخفضة الدقة

ملف الصورة: `assets/map-reference.jpg` (النسخة المرفقة الأصلية 500 × 708 بكسل).

- للحصول على أفضل نتيجة في شاشات 4K، اطلب نسخة واضحة أعلى دقة **بنفس القص والأبعاد النسبية 500:708**، مثل 2000 × 2832 بكسل.
- استبدل الملف الموجود بالملف الجديد **مع الحفاظ على الاسم نفسه**، ثم حدّث نسخة ذاكرة التخزين المؤقت في `sw.js` من `v1` إلى `v2` لضمان تنزيل الصورة الجديدة على الأجهزة التي خزّنت الإصدار السابق.
- تعتمد العلامات على نقاط بكسلية نسبية للخريطة الحالية (نظام داخلي 500 × 708). إذا تغير اقتصاص الخريطة أو محتواها فراجع مواضع العلامات ومسارات التمييز في `assets/app.js` و`index.html`.
- إذا توفرت إحداثيات GIS أو ملفات KML / GeoJSON معتمدة، يمكن إضافة طبقة شبكة طرق دقيقة في مرحلة لاحقة. النسخة الحالية **لا تستنتج أو تدّعي** إحداثيات الطرق وأطوالها أو تصنيفها الهندسي.

## ٥. الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة التطبيق الأساسية |
| `assets/styles.css` | الواجهة الحكومية والتجاوب مع الأحجام |
| `assets/app.js` | التفاعل، النقاط، الفلاتر، الجولة، إدارة البيانات |
| `assets/map-reference.jpg` | المخطط المرجعي الذي قدّمه المستخدم |
| `assets/road-icon.svg` | أيقونة تجريدية للطرق، **ليست شعارًا رسميًا** |
| `manifest.webmanifest` | معلومات تثبيت تطبيق الويب |
| `sw.js` | تخزين ملفات التطبيق للعمل دون اتصال بعد أول تحميل عبر HTTPS |

## ٦. معايير وقيود

- لا يستخدم التطبيق أي حزم خارجية، أو تتبع للمستخدمين، أو اتصالات لقاعدة بيانات.
- تدعم الواجهة RTL والتصفح بالفأرة ولوحة المفاتيح والتكبير باللمس.
- يتكيف تخطيط الصفحات مع الشاشات العريضة والرأسية، بما فيها 1080p و4K.
- عرض المخطط الأصلي ومواضع العلامات والتحديدات الملونة **استرشادي**، وليست بيانات مساحية أو إحصاءات رسمية. يُستحسن اعتماد نسخة محدّثة وواضحة من المخطط وإحداثيات معتمدة قبل أي استخدام هندسي.
- يظهر في تذييل التطبيق النص: **جميع الحقوق محفوظة لدائرة الطرق بمحافظة البريمي ٢٠٢٦م**.
